Ricochet Rumble

COMP 4021 1v1 tank maze duel — TA test guide.

Run the project

  1. npm install
  2. node server.js
  3. Open http://localhost:8000

Test accounts

  • tony / t
  • may / m

New accounts can also be registered on the start page.

Controls

  • WASD or arrow keys — move
  • Mouse — aim the turret
  • Space or left click — shoot
  • C — hidden cheat mode (invincible + rapid fire)

Pair up

Sign in with two different accounts in separate browsers or profiles. On both start pages, click Find Match. The server pairs the two players and starts the match on both browsers.

Practice mode

Click Play vs Bot on the start page, or open http://localhost:8000/?practice=1, for a local match against the practice bot.

The start page lists the controls, match rules, power-ups and global leaderboard. The cheat key is intentionally undocumented in the game UI.
